# NorthFlow

Маленький движок для разработки проектов по вертикальным срезам: идея → исследование → вопросы человеку → архитектура → независимая критика → документация → этапы → 3-5 ближайших задач → реализация → автопроверки → review → commit.

Северный поток вашего проекта: система ведёт проект от идеи до готовой работающей версии, а вы отвечаете только на важные вопросы на развилках.

## Почему не «ещё один агент»

Это не универсальный coding agent и не платформа с сотней режимов. Это маленький специализированный движок с фиксированным процессом:

```
idea → research → questions → architecture → critique → docs
→ roadmap → stage → 3-5 tasks → implementation → checks → review
→ commit → update state → next task
```

## Возможности

- **Вопросы с вариантами.** Модель сама спрашивает, что ей непонятно, а вы выбираете ответ цифрой или пишете свой.
- **Жёсткий scope-контроль.** Агент физически не может записать файл вне разрешённых путей своей роли.
- **Один писатель за раз.** Writer-lock не даёт двум агентам менять проект одновременно.
- **Лимиты ролей.** У каждой роли максимум запросов и времени; при лимите агент возвращает `PARTIAL` с результатом, а не исчезает.
- **Preflight до запуска.** Неправильная ветка, грязное дерево или отсутствие `AGENTS.md`/`docs/` останавливают агента до расхода токенов.
- **Память проекта.** Ответы человека и сохранённые факты попадают в контекст следующего агента.
- **Только русский для человека.** Все объяснения, вопросы и заметки — по-русски.

## Быстрый старт

```bash
cd engine
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e .
northflow init ~/projects/my-app
```

Настройка провайдера (`~/.northflow/config.json`):

```json
{
  "provider": "openai",
  "base_url": "https://api.openai.com/v1",
  "api_key": "sk-...",
  "model": "gpt-4.1-mini"
}
```

Запуск следующего шага конвейера:

```bash
northflow run ~/projects/my-app
```

## Команды

| Команда | Что делает |
|---|---|
| `northflow init <dir>` | Создаёт структуру проекта |
| `northflow run <dir>` | Выполняет следующий шаг конвейера |
| `northflow preflight <dir>` | Проверяет ветку, чистоту дерева, `AGENTS.md`, `docs/` |
| `northflow status <dir>` | Показывает фазу, этапы, задачи |
| `northflow questions <dir>` | Показывает сохранённые ответы |
| `northflow roadmap <dir>` | Перегенерирует `roadmap.md` |

## Как это устроено

- `state.py` — состояние проекта (`.northflow.json`), этапы, задачи, ответы, память.
- `config.py` — провайдер, модели ролей, бюджеты, разрешённые инструменты и пути.
- `agent.py` — агентский цикл «думай → действуй → наблюдай» с лимитами.
- `providers.py` — OpenAI-совместимый клиент.
- `tools.py` — инструменты: файлы, shell, web, память, finish; scope-check на уровне записи.
- `checks.py` — preflight и сканер запрещённых паттернов.
- `locks.py` — one-writer lock.
- `roles.py` — промты ролей: researcher, architect, critic, planner, developer, reviewer.
- `human.py` — интерактивные вопросы человеку.
- `implementation.py` — реализация задачи: preflight → lock → developer → проверки → review → commit.
- `planning.py` — импорт этапов и задач из markdown.

## Тесты

```bash
PYTHONPATH=src python3 -m pytest -q
```

Покрыты: scope-контроль, writer-lock, лимиты агента, парсинг этапов/задач, вопросы человеку, E2E (разрешённая запись проходит, запрещённая блокируется до изменения файла, commit создаётся).
