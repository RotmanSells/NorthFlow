# Changelog

Все заметные изменения в NorthFlow. Формат: [Semantic Versioning](https://semver.org/), разделы «Добавлено», «Изменено», «Исправлено».

## [0.1.0] — 2026-08-09

### Добавлено

- **Движок NorthFlow** — маленький специализированный движок для разработки проектов по вертикальным срезам.
  Конвейер: идея → исследование → вопросы человеку → архитектура → независимая критика → документация → этапы → 3-5 ближайших задач → реализация → автопроверки → review → commit → обновление roadmap/state.
- **Роли-агенты**: researcher, architect, critic, planner, developer, reviewer. Каждая роль — отдельная сессия со своим промтом, инструментами, моделью и бюджетом.
- **Интерактивные вопросы человеку**: агент возвращает вопросы с вариантами (`key`, `question`, `options`), CLI показывает нумерованный выбор, ответы сохраняются в `state.answers` и `memory`.
- **Только русский язык для человека**: во всех промтах ролей добавлено жёсткое правило русского языка; тексты инструментов, ошибок и CLI переведены на русский.
- **Scope-контроль на уровне записи**: `write_file`, `append_file`, `code_edit` физически отклоняют путь вне `allowed_paths` роли до изменения файла.
- **One-writer lock**: `.northflow.lock` не даёт двум писателям работать одновременно; добавлен stale-таймаут 15 минут (если процесс упал, старый lock освобождается автоматически).
- **Лимиты ролей**: у каждой роли максимум запросов и времени; при лимите агент возвращает `PARTIAL` с накопленным результатом, а не молча исчезает.
- **Preflight до запуска агента**: проверяет git-репозиторий, ветку, чистоту дерева, наличие `AGENTS.md` и `docs/`.
- **Запрещённые паттерны как gate**: `any`, `@ts-ignore`, `eval(`, `with(`, `async void`, `Thread.sleep(`, `JSON.parse(` в основном коде блокируют задачу.
  Исключения: `*.test.*`, `*.spec.*`, `scripts/`, `migrations/`, `*.generated.*`, строки с `FIXME` / `TODO: убрать`.
- **Снимок до/после задачи** (`snapshot.py`): хэши и количество строк файлов до и после; отчёт в `logs/task-N-*.json` (созданные, изменённые, удалённые, дельта строк).
- **Детектор зацикливания/бесполезности** в агентском цикле: если агент повторяет одинаковые вызовы или делает много инструментов подряд без результата — возвращает `STUCK` с уже собранным результатом.
- **Critical-change механизм**: разработчик может вызвать `critical_change`, если задача противоречит документации; задача становится `blocked`, вопрос сохраняется, commit не делается.
- **Commit guard**: полный цикл задачи — реализация → проверки → до 3 циклов исправлений → review → commit → roadmap; при FAIL проверок или найденных запретах коммит не создаётся.
- **Проверка плана** (`validate_plan`): у этапа должны быть название и описание/критерии, у задачи — название, описание, файлы и тесты; кривой план останавливает конвейер.
- **Persistent memory в проекте**: `.northflow.json` хранит фазу, этапы, задачи, ответы человека и память; сохраняется атомарно (tmp + replace).

### Изменено

- Пакет переименован с `flowpilot` на `northflow`: имя пакета, CLI (`northflow`), state-файл (`.northflow.json`), lock-файл (`.northflow.lock`), конфиг (`~/.northflow/config.json`).
- README полностью переписан: что такое NorthFlow, как работает конвейер, команды, структура кода, тесты.
- Агентский цикл: добавлен учёт токенов (`total_tokens`) и логи действий; при лимите — явный `PARTIAL`.
- Инструменты: добавлен `critical_change`; тексты ответов переведены на русский.

### Исправлено

- CLI `preflight` падал с `NameError` из-за отсутствующего импорта — импорт `preflight` добавлен.
- Lock-файл мог остаться навсегда после падения процесса — добавлен stale-таймаут.
- Сканер запрещённых паттернов существовал, но нигде не вызывался — теперь подключён как gate после реализации.

## Что ещё впереди (не в этом релизе)

- Векторная/семантическая память (обсуждается отдельно).
- Полный журнал сессий в `logs/` (что именно делал каждый агент).
- Подключение live-прогона на реальном проекте.
- Возможная автоматизация roadmap/stage-README после каждого этапа.
